# Westman Printing

A static Tailwind-based website for Westman Printing. This repository includes HTML, CSS, and JavaScript sources for the site, along with build tooling for Tailwind CSS.

## Project structure

- `index.html`, `about.html`, `contact.html` — main site pages
- `src/styles/tailwind.css` — Tailwind entry stylesheet
- `src/scripts/main.js` — page scripts
- `public/css/` — generated CSS output
- `lib/swiper/` — Swiper slider assets

## Getting started

```bash
npm install
npm run build
```
